# 📱 온디바이스 모바일 챗봇 (WebLLM)

휴대폰 **브라우저 안에서 직접** LLM을 실행하는 대전 복지 상담 챗봇입니다.
서버·API로 대화를 보내지 않습니다 — 모델이 어르신의 휴대폰에서 돌아갑니다.

- **모델**: Qwen2.5-1.5B-Instruct (4-bit, WebLLM) — 휴대폰에서 돌아가는 소형 모델
- **RAG**: 대전 독거노인 복지 자료 10종을 내장, "자료만 근거로" 답변(환각 차단)
- **실행**: WebGPU (최신 Chrome/안드로이드, Safari 18+/아이폰)

## 요구 사항
- **WebGPU 지원 브라우저**: 안드로이드 Chrome 최신, 아이폰 iOS 18+ Safari
- **첫 실행 시 인터넷**: 모델(~1GB)을 1회 내려받아 휴대폰에 캐시 → 이후 오프라인 동작
- 어느 정도 최신 휴대폰(RAM 4GB+ 권장)

## 휴대폰에서 여는 방법

### 방법 A — GitHub Pages (가장 쉬움, 링크만 열면 됨)
1. GitHub 저장소 → Settings → Pages → Branch를 이 브랜치로, 폴더 `/ (root)` 선택
2. 몇 분 뒤 생기는 주소 뒤에 `/mobile/` 를 붙여 휴대폰에서 열기

### 방법 B — 같은 WiFi의 PC에서 띄우기
```bash
cd ondevice_llm
python3 -m http.server 8000
# 휴대폰 브라우저에서  http://<PC_IP>:8000/mobile/  열기
```

### 방법 C — 홈 화면에 추가(PWA 느낌)
브라우저로 연 뒤 "홈 화면에 추가" → 앱처럼 전체화면으로 사용

## 발표 포인트
- **진짜 온디바이스**: WiFi를 꺼도(모델 캐시 후) 동작 → 대화가 휴대폰을 벗어나지 않음
- **개인정보**: 민감한 건강·정서 대화가 클라우드로 전송되지 않음
- **RAG 근거**: 작은 모델도 대전 공공자료에 근거해 환각 없이 답변
