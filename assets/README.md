# 이미지 자산 (hero 배경)

홈 화면 상단 "어르신, 무엇을 도와드릴까요?" 배너의 배경 그림을 여기에 넣습니다.

파일명을 **정확히** 아래 중 하나로 저장하세요 (앱이 자동으로 찾아 배경으로 사용):

- `assets/hero_bg.png`  ← 권장
- `assets/hero_bg.jpg`
- `assets/hero_bg.jpeg`
- `assets/hero_bg.webp`

파일이 없으면 자동으로 남색 그라디언트 배경으로 표시됩니다(앱은 정상 동작).
이미지는 페이지에 data-URI 로 내장되므로 외부 서버로 전송되지 않습니다(로컬 처리 원칙 유지).
